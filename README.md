## 🚀 核心增长公式

```
⭐ Stars = 价值 × 曝光 × 转化率 × 时间
```

- **价值**：项目解决了多大的真实问题
- **曝光**：多少目标用户看到了它
- **转化率**：看到的人里有多少愿意点星（由 README 和上手体验决定）
- **时间**：持续迭代与长尾内容的复利
